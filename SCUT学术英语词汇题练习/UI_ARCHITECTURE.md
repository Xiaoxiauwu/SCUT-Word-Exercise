# UI 模块说明

`UI.h` 是窗口层使用的公开接口，保留 `init`、`getScreenRect`、`MainUI`。内部实现位于 `scut_ui` 命名空间，窗口层不应直接访问内部状态。

| 模块 | 职责 |
| --- | --- |
| `UI.cpp` | 公开接口适配、页面分发、每帧渲染编排 |
| `UIInternal.h` / `UIState.cpp` | 内部协作接口与共享状态的唯一实例 |
| `UIRuntime.cpp` | ImGui、字体、资源与布局初始化 |
| `UIStorage.cpp` | 题库扫描、JSON 保存、用户数据持久化 |
| `UITheme.cpp` | 主题样式 |
| `UIDialogs.cpp` | 公共弹窗与弹窗栈绘制 |
| `UIHome.cpp` / `UIAbout.cpp` | 首页与关于页面 |
| `UIProblemSetSelection.cpp` | 练习题单选择 |
| `UIExercise.cpp` | 练习页面与抽题交互 |
| `UIProblemSetManager.cpp` / `UIEditor.cpp` | 题库管理与编辑页面 |
| `ExerciseSession.h` / `.cpp` | 练习会话数据、判题、错题收集，不依赖 ImGui 或 Win32 |
| `UIWrongAnswers.cpp` | 错题浏览、删除和撤销 |
| `UIMarkdown.cpp` | 轻量离线 Markdown、LaTeX 符号子集、题库图片纹理与链接渲染 |
| `QuestionModel.h` | 答案集合、收录去重、旧数据归一化和题单排序规则 |
| `ProblemSetEditor.h` | 题单编辑模型，不依赖 ImGui 或 Win32 |

`ExerciseSession` 统一保存当前题目、题号、正确数、抽题池、练习选项和每题的显示选项顺序；随机显示顺序不改写题目原始选项与答案索引。页面通过内部接口共享实例，不再各自定义这些状态。

每帧顺序为：应用主题 → 渲染当前页面 → 绘制弹窗 → 绘制转场遮罩 → 更新动画。弹窗回调执行前复制到局部，允许回调关闭自身或新增弹窗，而不销毁正在执行的函数对象。延迟回调引用的局部数据必须按值捕获。

新增页面时，在 `UIInternal.h` 声明渲染函数和页面标识，在独立源文件实现，并在 `UI.cpp` 注册分发。业务规则优先放入模型，避免在渲染函数内新增文件操作或判题规则。

题目格式兼容旧单选题，新增 `type`、题单 `order` 和练习过程字段 `Selected`、`WrongAnswerPolicy`。用户数据继续保存为原编码格式，错题加载时归一化和去重。错题练习抽取快照，不清空持久错题集。`ExerciseSession::submitCurrent` 只判当前题，`finish` 跳过最后一题中未作答的题目，`gradedCount` 为结算分母。

收录策略：0 跟随练习设置，1 强制收录，2 排除。策略同步到本轮同题记录和抽题池，避免移除后因重复抽取重新加入。多选自动判题禁用，只在手动提交或结算时比较答案集合；“判题”批量提交所有已有选择且尚未判定的题目。题库排序通过 `OrderedProblemSetNames` 统一实现，索引默认 1000，同索引按数字自然排序。

## 模型回归测试

### 窗口与字体

`GUI.cpp` 保留隐藏的 Win32/DX11 宿主并启用 ImGui 多视口。界面由 ImGui 的无标题栏窗口显示，设置 `ConfigViewportsNoDecoration` 与 `ConfigWindowsResizeFromEdges`，通过 ImGui 原生边缘和角落拖拽调整尺寸。初始位置、尺寸仅通过 `ImGuiCond_FirstUseEver` 设置，`SetNextWindowSizeConstraints` 回调按主要拖动方向锁定 3:2 比例，最小尺寸为 660 × 440；使用 3 × 2 像素步长避免整数取整导致比例漂移。

`UIRuntime.cpp` 在 `Begin` 后读取 `GetWindowSize` 更新页面宽高，页面直接使用整个 ImGui 窗口。窗口约束与缩放系数计算放在 `UILayout.h`，以 960 × 640 为基准保持 3:2 比例，不产生居中留边。题单选择页面在宽或高改变后重置依赖旧布局的动画偏移。

字体仅在初始化时生成一份固定 20 px 的完整中文字库，关闭过采样并取消图集高度向 2 的幂取整；上传 GPU 后释放 CPU 像素副本。普通控件以 16 px 为基准，通过 `FontGlobalScale` 乘以窗口宽度 / 960，并立即刷新 ImGui 当前帧字体缓存；自绘文字通过 `setTextScale(0.85f)` 统一缩小，测量与绘制使用同一比例。两类文字均随窗口宽度线性缩放，自绘文字不重复叠加倍率。缩放不重建字体图集，因此字体内存不随窗口尺寸增长。极大窗口下自绘文字可能模糊。

### 回归范围

测试覆盖判题幂等、未作答结算、跳过末尾未作答题、错题状态重置、独立会话，以及题单编辑和保留最后一题。

布局测试覆盖最小窗口、普通窗口、1080p、4K 和竖向窗口，验证字体参考尺寸的比例与边界，并确认 1561 上限已移除。

在仓库根目录使用支持 C++17 的 g++ 执行：

```powershell
g++ -std=c++17 -I "SCUT学术英语词汇题练习" tests/ui_models_test.cpp "SCUT学术英语词汇题练习/ExerciseSession.cpp" "SCUT学术英语词汇题练习/jsoncpp.cpp" -o output/ui_models_test.exe
./output/ui_models_test.exe
```

约束测试覆盖水平、垂直、角落拖拽和最小尺寸，验证 3:2 比例及 1、1.5、2 倍字体缩放系数。

新增回归覆盖：多选漏选/多选/全对、旧单选兼容、手动收录与排除、重复抽题状态重置、错题练习保留与答对移除、旧重复记录迁移、删除选项后的答案重映射、自然排序与显式索引、结算跳过末尾未作答题及正确率分母。

## 页面布局约束

现有页面沿用原布局：主页居中菜单按钮与底部署名，“错题管理”位于“错题练习”下方；题单选择保留竖排分类、动画题单按钮与右侧“开始抽题”；练习保留左侧双列选项按钮、右侧十列题号方格、底部自动判题控件和原结算弹窗。新增错题收录选项收进右上角“错题设置”，不占据原练习区域。题库管理与编辑继续使用原来的卡片结构和选项编辑图标。后续功能补充应在这些布局上局部增加控件，不替换页面结构。

题单卡片在空白区域启动鼠标拖动，整张卡片按抓取偏移跟随鼠标；插入位置变化时其他卡片以指数缓动移动并预留占位。松开后写入新的 `order` 并保存，Esc 取消并缓动回位，列表边缘支持自动滚动。界面不显示排序索引输入。错题以 `LastWrongAt` 毫秒时间戳稳定升序显示（最近在底部），同题重收录更新时间；旧记录按原顺序补时间，撤销删除保留时间。

题面与选项由 `UIMarkdown` 在 ImGui 内离线渲染，支持标题、列表、强调、行内代码、HTTP(S)/mailto 链接和题库目录相对图片；公式仅转换常见 LaTeX 命令为 Unicode 数学符号，不依赖外部运行时，也不实现完整 TeX 排版。
